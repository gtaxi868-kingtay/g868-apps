# G-Taxi 868 apps

Android downloads for G-Taxi 868 (Trinidad and Tobago).

Get the app at **https://g868.vercel.app/get**

This repository holds only the installable app files, attached to Releases. The app source code is not here.

- G Rider: book rides, order from shops near you
- G Driver: take rides, keep up to 80% of every fare
- G Business: take orders and put your shop on the map

Android 7 or newer. The apps update themselves after install.
